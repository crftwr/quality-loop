# jot

jot keeps a list of short notes, one per line.

## Moving around

The selected note is marked with `>`. Up and Down move the selection.

## Adding a note

Press `a`, type the note, and press Enter. Esc gives up.

## Changing a note

Select it and press `r`. The note's text appears at the bottom, ready to
change; press Enter to keep the new text.

## Deleting a note

Select it and press `d`.

## Leaving

Press `q`. Every change is saved as you make it.
